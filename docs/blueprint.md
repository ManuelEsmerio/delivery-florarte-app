# **App Name**: DriveMate

## Core Features:

- Secure Driver Authentication: Enable drivers to log in securely using their email and password, utilizing JWT for session management and access control.
- Assigned Order Dashboard: Provide a clear overview of all assigned delivery orders, displaying key information such as order number, customer name, delivery address, scheduled time, and current status.
- Detailed Order Information: Present comprehensive details for a selected order, including customer contact, full address, an interactive map location, list of order items, and any specific delivery notes.
- Route Initiation & Status Updates: Allow drivers to explicitly start a delivery route, updating the order status to 'in_route' and enabling subsequent status changes (e.g., 'delivered', 'failed').
- Proof of Delivery Capture: Facilitate the collection of required proof upon delivery, including the receiver's name, a captured signature image, optional observations, precise GPS coordinates (latitude, longitude), and the exact delivery timestamp.
- Driver Profile Management: Enable drivers to manage their account details, specifically allowing them to securely change their password.

## Style Guidelines:

- Primary action color: A professional and trustworthy medium-dark blue (#2252C9). This hue was chosen to evoke reliability and efficiency, common traits in logistics. It provides a strong contrast against lighter backgrounds, ensuring high visibility for interactive elements.
- Background color: A very light, desaturated blue-grey (#ECF0F7). This color is derived from the primary blue, offering a subtle coherence while ensuring a clean, uncluttered visual space conducive to easy readability and minimal eye strain.
- Accent color: A vibrant, clear cyan (#15C6EC). This color, analogous to the primary blue, is distinct in saturation and brightness. It will be used sparingly to draw attention to critical calls-to-action or notifications, providing clear visual hierarchy without being overwhelming.
- Headline and body font: 'Inter' (sans-serif). Chosen for its modern, neutral, and highly readable characteristics across various screen sizes. This font supports the app's requirement for simplicity and clarity, ensuring driver-friendly information consumption.
- Utilize simple, universally recognizable, filled icons that are clearly visible and provide immediate contextual understanding. Icons should complement large touch buttons for effortless interaction while driving or on the go.
- Emphasize clean, spacious layouts with generous padding and clear information hierarchy. Crucially, interactive elements such as buttons must be large and easily tappable to support driver-friendly operation and minimize errors, reflecting a 'minimal steps' design philosophy.
- Incorporate subtle, performant animations for screen transitions and user feedback. Animations should enhance the user experience by indicating actions and state changes without introducing any perceptible delays or slowing down app interactions, aligning with the 'fast' requirement.
